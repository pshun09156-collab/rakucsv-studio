楽天CSVの「スマートフォン用商品説明文に許可されないHTMLタグ」エラーの直し方｜div・span・styleが使えない理由

楽天市場（RMS）にnormal-item.csvをアップロードしたら、「スマートフォン用商品説明文に許可されないHTMLタグ "div" が含まれています」「許可されない "style" 属性が含まれています」といったエラーで弾かれた——。

先に結論です。スマートフォン用商品説明文は、PC用の説明文と比べてHTMLタグの制限が格段に厳しく、div / span / h2 / table といったタグや style 属性が使えません。 対処法は、PC用のHTMLをそのままコピーするのをやめ、スマホ用は <br> を中心としたプレーンなテキストで作り直すことです。

この記事では、説明文カラム3種の違い、スマホ用の安全な書き方、そして見落としがちな10240byte上限と分割テクニックまで解説します。

結論：スマホ用だけタグ制限が厳しい

このエラーが出るのは、ほぼ例外なく PC用商品説明文のHTMLをそのままスマートフォン用商品説明文にコピーしたケースです。

PC用の説明文は比較的寛容で、table によるレイアウトやインラインの style 指定も通ります。そのため「PC用で通ったHTMLだからスマホ用でも通るはず」と考えてしまいがちですが、スマホ用は別ルールで、レイアウト目的のタグや装飾指定は受け付けられません。つまり、同じ内容でもPC用とスマホ用は別々に書く必要があります。まずコピー元がPC用HTMLでないかを疑ってください。

説明文カラムは3種類ある：それぞれの違い

normal-item.csvには説明文系のカラムが3つあります。役割と制限が異なるので、まず違いを押さえます。

カラム名 表示先 HTMLの自由度 byte上限
PC用商品説明文 PC版商品ページ 比較的寛容（table・インラインstyle可） 10240
スマートフォン用商品説明文 スマホ版商品ページ 厳しい（div/span/h2/table・style属性は不可） 10240
PC用販売説明文 PC版商品ページの下部 比較的寛容（PC用商品説明文と同様） 10240

いずれのカラムも必須項目ではありませんが、商品ページの訴求を担う部分なので実質的には必ず書くことになります。

なお、PC用が寛容といっても無制限ではありません。外部CSSファイルや外部JavaScriptの読み込みは使えません。装飾はインラインで完結させる必要があります。

スマートフォン用商品説明文の書き方：<br> 中心で組み立てる

スマホ用は「HTMLでレイアウトを組む場所」ではなく、「改行の入ったテキストを置く場所」と考えるのが実務的です。

避けるべきタグ・属性

エラーの原因になりやすいのは次のものです。

  • <div> / <span>：レイアウト・装飾用のタグ
  • <h2> などの見出しタグ
  • <table> / <tr> / <td>：表組み
  • style 属性（<p style="..."> のようなインライン指定を含む）

PC用から流用したHTMLには、これらがほぼ確実に含まれています。エディタの置換機能で機械的に洗い出すか、後述のツールで検出してください。

表組みをやめて改行で並べる

PC用でスペック表を <table> で組んでいる場合、スマホ用では改行区切りの箇条書きに置き換えます。

■商品仕様<br>
メーカー：ヤマハ<br>
型番：YDP-166B<br>
カラー：ブラック<br>
<br>
■セット内容<br>
本体、専用スタンド、取扱説明書<br>

見出しも <h2> ではなく、■ や 【】 などの記号で代用します。装飾は減りますが、そもそもスマホの画面幅では横長の表は読みにくく、改行区切りのほうが読みやすいことも多いです。

説明文の中の <img> に注意

説明文HTMLの中に <img> で画像を入れている場合、その画像はCSVの商品画像カラムとは別物です。公開ページで表示させるには、R-Cabinetにアップロード済みの正しいURL／パスを指定する必要があります。画像を使わない商品でテンプレートを流用すると、<img> だけが残って画像切れになることがあるので、使わないなら説明文からも除去してください。

見落としがちな10240byte上限と分割テクニック

タグ制限と並んでつまずきやすいのが、各説明文カラムの10240byte上限です。

byte数の考え方

上限は文字数ではなくbyte数です。normal-item.csvはShift-JIS（cp932）で保存するため、全角文字は1文字あたり2byte換算になります。単純計算で全角約5,000文字が目安ですが、HTMLタグも当然byte数に含まれる点に注意してください。装飾の多いHTMLは、見た目の文章量よりずっと早く上限に達します。

PC用は「商品説明文」と「販売説明文」に分割できる

PC用の説明文が10240byteを超えてしまう場合、PC用商品説明文に前半、PC用販売説明文に後半を入れて分割するのが定番の対処です。PC用販売説明文は商品ページの下部に表示されるため、上から読んだときに自然につながります。

分割の切れ目は、「商品の訴求・特徴」までを前半、「スペック表・注意事項・配送について」などを後半、といった区切りにすると読み手にも自然です。

スマホ用は分割先のカラムがないため、そもそも情報を絞って書く必要があります。タグを減らして <br> 中心にするだけでもbyte数はかなり削れるので、この点でもプレーンな書き方が有利です。

あわせて注意：ダブルクォートのエスケープ

CSVのセル内にHTMLを書くとき、HTML中の " は "" と二重にしてエスケープします（CSVの標準的なルールです）。やってはいけないのが、" を &quot; に一括置換することです。一見安全そうですが、インラインstyleなどのHTMLが壊れて意図した表示になりません。

また、説明文に ™ ® © ①②③ や絵文字などの環境依存文字が混ざっていると、cp932で表現できずアップロード時に文字化けとして弾かれます。「①→1.」「©→(c)」のように置換するか、削除してください。

スマホ用説明文の禁止タグを自動検出できる無料ツール

説明文が長くなるほど、div や style の消し忘れを目視で探すのは現実的ではなくなります。商品数が多ければなおさらです。

無料のブラウザツール RakuCSV Studio の点検機能を使うと、手元のnormal-item.csvを読み込ませるだけで、スマートフォン用商品説明文に含まれる許可されないタグ・属性を自動で検出できます。あわせて、文字コード（UTF-8保存）の問題、ヘッダー名の誤記、環境依存文字の混入といった別系統のエラー要因も同時に診断し、修正済みのCSVをダウンロードできます。ブラウザ上で動くのでインストールは不要です。

さらに詳しく：CSV登録を「一発で通す」ために

説明文のタグを直しても、その先には「ジャンルIDが古い」「カタログIDもしくはカタログIDなしの理由が必須」「必須の商品属性が未入力」「画像パスは相対パスでご指定ください」など、系統の異なるエラーが控えています。
