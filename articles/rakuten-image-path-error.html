楽天CSVの「画像パスは相対パスでご指定ください」エラーの直し方｜R-Cabinetの相対パスの書き方

楽天市場（RMS）にnormal-item.csvをアップロードしたら、「画像パスは相対パスでご指定ください」というエラーで弾かれた——。

先に結論です。原因は、商品画像パスに https:// から始まるフルURLを入れていることです。楽天のCSVでは、画像はフルURLではなく /フォルダ名/ファイル名.jpg という相対パスで指定します。

そしてもう1つ、前提として押さえておくべき重要な点があります。画像はあらかじめR-Cabinetにアップロードしておく必要があり、CSVから画像そのものをアップロードすることはできません。 CSVに書くのは「すでにR-Cabinetにある画像の場所」だけです。

この記事では、相対パスの正しい書き方、画像系カラムの番号ルール、画像を使わない場合の扱い、そして「登録は通るのに画像が表示されない」ケースまで解説します。

結論：フルURLではなく相対パスで書く

商品画像パスの書き方は次のとおりです。

書き方 例 可否
フルURL https://image.rakuten.co.jp/shop/cabinet/item/img01.jpg 不可（このエラーになる）
相対パス /item/img01.jpg 可

相対パスは、R-Cabinet内のフォルダ構成をそのまま /フォルダ名/ファイル名.jpg の形で書いたものです。R-Cabinetを開き、対象画像が入っているフォルダ名とファイル名を確認して転記してください。ブラウザからコピーした画像URLをそのまま貼り付けるとフルURLになります。エラーの大半はこのパターンです。

前提：画像は先にR-Cabinetへアップロードしておく

CSVで商品を一括登録するとき、画像ファイル自体をCSVと一緒にアップロードすることはできません。手順は必ず次の順番になります。

  1. R-Cabinet（またはGOLD）に画像をアップロードする
  2. アップロード先のフォルダ名・ファイル名を確認する
  3. その相対パスをnormal-item.csvの画像パスカラムに書く
  4. CSVをアップロードする

「CSVに画像ファイル名を書いておけば、あとで画像を上げれば紐づく」という発想は通用しません。画像の準備が先です。なお、画像の置き場所が R-Cabinet と GOLD のどちらかは、商品画像タイプ カラムで cabinet または gold と指定します。

画像系カラムの番号ルール：SKU画像だけ番号が付かない

画像系のカラムは種類が多く、しかも番号の付き方が統一されていないため、ヘッダー名の誤記で「項目名が正しくありません」と弾かれる原因にもなります。

カラム名 番号 内容
商品画像タイプ1〜24 あり cabinet または gold
商品画像パス1〜20 あり 相対パス（半角255byte以内）
商品画像名（ALT）1〜20 あり 代替テキスト（255文字以内）
SKU画像タイプ なし cabinet または gold
SKU画像パス なし 相対パス
SKU画像名（ALT） なし 代替テキスト

商品レベルの画像カラムには番号が付きますが、SKUレベルの画像カラムには番号が付きません。SKU画像タイプ1 と書くのは誤りで、正しくは SKU画像タイプ です。商品画像のほうに番号が付いているせいで、つい揃えて番号を振ってしまうのがよくあるミスです。白背景画像用の 白背景画像タイプ / 白背景画像パス も番号なしで、パスは同じく相対パスです。

画像を使わない場合：画像系カラムはすべて空にする

商品ページに画像を使わない、あるいはCSVでは画像を触らずに後からRMSの画面で設定する、というケースもあります。

その場合は、画像系のカラムをすべて空にするのが安全です。中途半端に cabinet だけ入っていて画像パスが空、あるいは逆にパスだけ入っていてタイプが空、といった状態はエラーの原因になります。使わないなら列ごと空、が原則です。

過去のCSVを流用するときは特に注意してください。前の商品の画像パスが残ったまま新商品を登録すると、まったく関係ない画像が表示されてしまいます。

「登録は通るのに画像が表示されない」ケース

パスの形式は正しく、CSVのアップロードもエラーなく完了したのに、公開ページで画像が表示されない——という相談もよくあります。主な原因は次のとおりです。

原因1：R-Cabinetに実物がない／パスの綴りが違う

相対パスの形式が正しくても、その場所に画像が存在しなければ表示されません。フォルダ名・ファイル名の綴り、拡張子（.jpg と .jpeg の違いなど）、大文字小文字を1文字ずつ確認してください。CSVは「形式が正しいパス」を受け付けるので、実在しないパスでも登録自体は通ってしまいます。

原因2：説明文HTML内の <img> は別カラム扱い

PC用商品説明文やスマートフォン用商品説明文の中に <img> タグで入れた画像は、商品画像カラムとはまったくの別物です。商品画像パスを直しても説明文内の画像は直りません。説明文の <img> は、その src に書かれたR-Cabinetの正しいURL／パスを個別に見直してください。

逆に、画像を使わない商品なのに説明文テンプレートを流用して <img> だけが残り、画像切れになるケースもあります。使わないなら説明文からも <img> を除去します。

原因3：CSVそのものが正しく読み込まれていない

CSVをUTF-8で保存していると、ヘッダーが文字化けして全項目が「項目名が正しくありません」で弾かれます。normal-item.csvは Shift-JIS（cp932） で保存してください。一部の画像カラムだけがエラーになる場合は、前述の番号ルールなどヘッダー名の誤記を疑います。

画像パスの書式ミスを自動チェックできる無料ツール

商品数が増えると、「どの行の画像パスがフルURLのままか」「タイプとパスの片方だけ埋まっている行はどれか」を目視で探すのは大変です。

無料のブラウザツール RakuCSV Studio の点検機能を使うと、手元のnormal-item.csvを読み込ませるだけで、フルURLになっている画像パスを自動で検出できます。あわせて、文字コード（UTF-8保存）の問題、SKU画像タイプ などのヘッダー名の誤記、環境依存文字の混入、カタログID等の必須項目の欠落も同時に診断し、修正済みのCSVをダウンロードできます。ブラウザ上で動くのでインストールは不要です。

さらに詳しく：CSV登録を「一発で通す」ために

画像パスを直しても、その先には「ジャンルIDが存在しない・古い」「カタログIDもしくはカタログIDなしの理由が必須」「必須の商品属性（ブランド名・メーカー型番・代表カラー）が未入力」「スマートフォン用商品説明文に許可されないHTMLタグ」など、系統の異なるエラーが控えています。
