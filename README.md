# RakuCSV Studio (β)

**楽天市場の商品一括登録CSV(normal-item.csv / SKU対応)を、ブラウザだけで作成・点検できる無料ツールです。**

👉 **使ってみる: https://pshun09156-collab.github.io/rakucsv-studio/**

## できること

### CSVを作る
- フォーム入力から、RMSにそのままアップロードできる `normal-item.csv` を生成
- **Shift-JIS出力** — UTF-8保存による「項目名が正しくありません」全弾きエラーを回避
- **単品・マルチSKU対応** — カラー×サイズ等のバリエーション2軸からSKU表を自動生成
- **環境依存文字の自動置換** — ™・①・—・絵文字などの文字化けエラーを未然に防止
- スマホ用説明文の禁止タグ検出、必須項目・形式チェック、SKU番号の重複検出

### 手持ちのCSVを点検する
- アップロード前のnormal-item.csvを診断: 文字コード / ヘッダー誤記 / 列ずれ / 必須項目 / SKU重複 / 禁止タグ / 画像パス / カタログID要件 / 環境依存文字
- UTF-8保存・ヘッダー誤記・環境依存文字は**修正済みCSVを自動生成**してダウンロード可能

## 安心して使えます

- **完全クライアントサイド処理** — 入力した商品データはお使いのブラウザ内でのみ処理され、サーバーには一切送信されません
- 登録・インストール不要、無料

## 使い方

1. 上のURLを開く
2. 商品情報・SKU情報を入力 →「チェックしてCSVを生成」
3. エラー・警告を確認し、`normal-item.csv` をダウンロード
4. RMSの商品一括編集(またはSFTP `/ritem/batch/`)にアップロード

詳しい攻略情報は **[楽天CSV完全攻略ガイド(¥980・エラー辞典/チェックリスト付き)](https://note.com/midas_works/n/ncad7544d90c8)** をどうぞ。
